DATA TRANSPARENCY

Science needs context.

Educational visualization of curated dates, not an authoritative ephemeris.

Data sources

The original orbital.json records object names, periods, images and dated events. These may be incomplete, approximate or outdated.

Progress is not orbital position

When two listed dates bracket today, we show the fraction of calendar days elapsed between them. This does not indicate physical orbital position or distance; orbital speed varies.

No invented future events

We do not extrapolate missing perihelion dates. Objects with insufficient data have no progress bar. Use current professional ephemerides for scientific work.

Lightweight architecture

Python generates static HTML and JSON with atomic file replacement. No tracking, database, JavaScript framework or server-side app is required.
